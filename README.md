# МедСверка

Небольшое Flask-приложение сравнивает до 200 врачей из Medical API с врачами из всех 30 HTML-страниц Doctor Catalog (350 карточек). На странице доступны поиск, фильтр по статусу и сравнение данных двух источников.

## Запуск в Docker

Установите Docker Desktop и создайте файл `.env` на основе примера:

```powershell
copy .env.example .env
```

Откройте `.env` и замените значение `MEDICAL_API_KEY` на настоящий ключ. Файл `.env` исключён из Git и Docker-образа; ключ используется только сервером и не передаётся в браузер.

Запустите приложение одной командой:

```powershell
docker compose up --build
```

Откройте **http://127.0.0.1:5000/**. Первая загрузка и каждое нажатие «Обновить данные» запрашивают свежие данные из обоих источников.

Для остановки нажмите `Ctrl+C`. Чтобы запустить контейнер в фоновом режиме, используйте `docker compose up --build -d`, а для остановки — `docker compose down`.

## Как работает сопоставление

- **Совпало** — полностью совпали нормализованные ФИО (включая другой порядок слов) и специальность. `Ё/е`, регистр, знаки препинания и лишние пробелы игнорируются.
- **Возможно совпадение** — специальность совпала, фамилия и остальные части ФИО достаточно похожи. Такие записи отмечены причиной и требуют ручной проверки.
- **Только в Medical API / Только в каталоге** — подходящей пары не найдено. Каталог-only означает, что подходящей записи нет среди 200 полученных специалистов API.
- Различия стажа, ФИО и специальности выделяются оранжевым. Для каталога дополнительно показываются клиника, публичная цена и ссылка на карточку.

При ошибке источника на странице отображается сообщение, а не трассировка или ключ. При пустом результате поиска предлагается сбросить фильтры.
